# Push to GitHub later

```bash
cd /documents/cubahotels
git push -u origin main
```

If GitHub `main` already has commits you want to replace:

```bash
git push -u origin main --force
```

Remote is already set to: `https://github.com/otouristas/cubahotels.git`

Local setup after clone/copy:

```bash
npm install
npm run dev
```
